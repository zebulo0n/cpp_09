# CPP Module 09

STL containers and algorithms (C++98).

- **ex00 – Bitcoin Exchange**: compute the value of BTC amounts from a historical price database.
- **ex01 – RPN**: evaluate Reverse Polish Notation expressions.
- **ex02 – PmergeMe**: sort a sequence with merge-insertion (Ford-Johnson) using two different containers and compare timings.

## Usage

```sh
make
./btc input.txt
./RPN "8 9 * 9 - 9 - 9 - 4 - 1 +"
./PmergeMe 3 5 9 7 4
```
